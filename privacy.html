Hermes Privacy Policy

Effective date: November 15, 2026

What Hermes accesses

Hermes is a private tool used only by its owner. It accesses only the owner's own Google account data:

  • Gmail (read-only)
  • Google Calendar (read-only)
  • Google Drive (read-only)
  • Google Contacts (read-only)
  • Google Sheets and Google Docs that the owner shares with it

How data is processed

Data is processed on the owner's own computer and by the AI model provider the owner has configured.

How data is not used

No data is sold, shared with third parties for advertising, or used for any purpose other than the owner's own assistance.

Google API Services User Data Policy

Hermes's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.
